# 여론 확산 모델 명세 v0.1

기레기 시뮬레이터 런타임의 창발적 여론 확산 엔진. 계보: bounded-confidence 여론 동역학(Deffuant / Hegselmann-Krause)에 **확증편향 대역 축소 + 역풍(backfire) + 톤×감정 공명 + 도달 게이트 + 관성**을 얹은 형태.

핵심: 플레이어가 A를 눌렀을 때 결과가 확정되지 않는다. `conf × emo`의 상호작용이 세그먼트마다 다른 비대칭을 만들고, 규모 가중 거시 여론이 그 위에서 창발한다 → 규칙표(if문)로 못 짠다 = 런타임 AI의 정당성.

---

## 1. 상태 변수

- 세그먼트 `s`의 여론 위치 `x_s ∈ [0,1]` (0=완전반대, 0.5=중립, 1=완전찬성). 매 턴 갱신.
- 고정 성향: `x0_s`(기존입장=앵커), `emo_s`(감정반응성), `conf_s`(확증편향), `size_s`(규모), `reach_s{old,sns}`(매체소비).
- 전역: 평판 `R ∈ [floor,1]`, TV 거시 여론 `TV`(지연값).

## 2. 레버 → 축 매핑

| 레버 | 인코딩 | 물리는 축 |
|---|---|---|
| 프레임 | 위치 `p` (반대각 0.2 / 중립 0.5 / 찬성각 0.8) | 확증편향 (`p`가 `x`에서 멀면 튕김) |
| 톤 | 자극 / 중립 / 차분 | 감정반응성 (`E` 계산) |
| 채널 | old / sns | 매체소비 (`reach` 게이트) |
| 사실왜곡 | `δ ∈ [0,1]` | 즉시 이동폭 부스트 ↔ 발각 리스크 |

## 3. 한 턴 갱신식 (세그먼트별)

```
r      = reach_s[channel]                      # 도달 게이트 (0이면 무효)
ε_s    = εmax · (1 − conf_s)                    # 확증편향이 좁히는 수용 대역
d      = |p − x_s|                              # 프레임 각도와의 거리
E      = 자극: emo_s | 중립: 0.5 | 차분: 1 − emo_s   # 톤×감정 공명

if d ≤ ε_s:      # 수용 → 프레임 쪽으로
    dir      = sign(p − x_s)
    strength = 1 − d/ε_s
else:            # 거부 → 역풍(반대쪽으로 파고듦)
    dir      = sign(x_s − p)
    strength = backfireCoef · conf_s · min(1, (d − ε_s)/(1 − ε_s))

Δpull   = k · r · E · strength · dir · R · (1 + δ·distortionGain)
Δanchor = − λ · (x_s − x0_s)                    # 기존입장으로의 관성
x_s ← clamp01(x_s + Δpull + Δanchor)
```

## 4. 거시 여론 & 접전도

```
O        = Σ size_s · x_s          # 규모 가중 평균 (즉시 미시 = 화면3)
TV       ← TV + α · (O − TV)        # 저역통과 지연 (거시 = 화면2, 시차 발생)
접전도   = 1 − |2O − 1|             # 0.5 근처=1, 극단=0
```

## 5. 발각 (확률 누적식, 단발성 충격)

왜곡할수록 발각 확률 `riskProb`이 쌓이고, 매 턴 그 확률로 굴려 걸리면 **한 번의 충격**이 온다. 충격 크기는 **걸린 시점의 `riskProb`에 비례** — 일찍 걸리면 작고, 오래 끌다 걸리면 크다. 발각은 원샷(평판과 역할 분리).

```
# 누적
if δ > 0:  riskProb ← clamp01(riskProb + manipStep·δ)     # 왜곡할수록 증가
else:      riskProb ← max(0, riskProb − honestDecay)       # 정직하면 냉각

# 굴림 (접전일수록 잘 들통남 = 화면2 TV 읽기 메커닉)
effProb = clamp01(riskProb · (1 + cw·(접전도 − 0.5)·2))
if rand() < effProb:                                        # 발각
    damage = damageK · riskProb                             # 걸린 시점 확률에 비례
    lean   = sign(p − 0.5)                                  # 최근 밀던 방향
    for each s:  x_s ← clamp01(x_s − lean · damage·(0.5 + 0.5·emo_s))  # 밀던 반대로 등 돌림
    R ← max(floor, R − accuracyRepPenalty)                  # 평판 사실정확성 축 하락(지속)
    riskProb ← riskProb · resetOnDetect                     # 스캔들 소모
```

- `cw`(contestednessWeight)=0이면 순수 누적, >0이면 접전 상태에서 발각률 상승.
- 감정 집단(`emo`↑)이 배신감에 더 크게 등 돌림 → 부동층·자기 진영까지 타격.

## 6. 평판 (지속 계수 — 논조 + 사실정확성)

두 축을 함께 추적하며, `R`이 **모든 이동폭을 곱으로 감쇠**한다(원샷 아님).

- **논조 일관성**: 직전 프레임 대비 논조가 반대로 급변 → `R ← max(floor, R − swingPenalty)`, 유지 → `R ← min(1, R + recover)`.
- **사실정확성**: 왜곡이 **발각으로 드러나면** `R ← R − accuracyRepPenalty` (안 걸리면 숨겨진 채 유지 = 도박 성립).

→ 판을 뒤집으려 논조를 바꾸면 영향력을 잃고(논조 축), 지름길로 왜곡하다 걸리면 신뢰가 무너진다(정확성 축).

### 발각 몬테카를로 (`node montecarlo.mjs`, N=4000)

| 전략 | 승률 | 발각 경험 | 마감 부동층 | 해석 |
