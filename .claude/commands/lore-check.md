description: lore check — canon 모순·공백 후보 리포트 (기계 검사 + 의미 검사)
argument-hint: (인자 없음) [--canon <경로>]
---

너는 게임 개발 파이프라인의 오케스트레이터다. `lore check` 를 실행한다.
계약: `pipeline/commands/lore.md` 의 `lore check` 절. 역할 분담: 기계 검사=스크립트, 의미 검사=너.

**목적**: `lore/canon/` 정본의 모순·공백 후보를 리포트한다. 이 명령은 **읽기 전용**이다 — canon 을 수정하지 않는다.

## 1. 생성 — 기계적 검사 (스크립트)

```
python3 pipeline/scripts/lore_check.py --canon lore/canon
```
- 검출: `duplicate_glossary_def`(error), `notation_mismatch`(warning), `undefined_term`(info), `orphan_term`(info).
- 종료 코드: 0=error/warning 없음, 1=검출됨, 2=실행 오류. (경로가 다르면 `--canon <경로>` 인자를 사용자 요청대로 넘긴다.)

## 2. 판단 — 의미적 검사 (너의 몫)

스크립트가 **하지 못하는** 판단 검사를 직접 수행한다. canon 문서를 읽고 규칙으로 판정 불가한 결함 후보를 찾는다:
- **설정 충돌**: 세계 규칙(world.md)과 세력/인물 서술이 모순되는가? (예: "마법은 소실됐다"고 해놓고 특정 세력이 마법을 상시 사용)
- **연대기/인과 불일치**: 사건 순서·시점이 어긋나는가?
- **공백**: 핵심 갈등·세력의 동기 등 참조될 설정이 비어 있는가?
- 각 지적은 반드시 canon 근거(`파일:줄` 또는 인용)와 함께 제시한다. 근거 없는 추측은 하지 않는다.

## 3. 통합 리포트 (사람 검수)

기계 검사 결과 + 의미 검사 결과를 하나의 리포트로 제시한다:
- 심각도별로 묶고, 각 항목에 `파일:줄`·근거·권장 조치를 붙인다.
- 표기 불일치는 어떤 표준 표기로 통일할지 후보를 제안한다.
- **이 명령은 canon 을 고치지 않는다.** 수정이 필요하면 사용자 승인하에 별도 조치(수동 수정 또는 향후 `lore edit`)로 진행하라고 안내한다.

주의: 어떤 결함도 canon 을 자동 수정하지 말 것. lore check 는 검출·보고까지만 책임진다.
