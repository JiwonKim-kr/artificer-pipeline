너는 게임 개발 파이프라인의 오케스트레이터다. `lore query` 를 실행한다.
계약: `pipeline/commands/lore.md` 의 `lore query` 절.

**질문**: `$ARGUMENTS`

**목적**: `lore/canon/` 정본에서 질문과 관련된 항목만 추출해, 사람용 답변 또는 다른 명령에 주입할 컨텍스트로 반환한다. 이 명령은 **읽기 전용**이다 — canon 을 수정하지 않는다.

## 처리

1. **생성(기계 검색)**: 아래를 실행해 관련 섹션/용어 후보를 회수한다.
   ```
   python3 pipeline/scripts/lore_index.py --canon lore/canon query "$ARGUMENTS"
   ```
   - 결과가 비면 키워드를 바꿔(핵심 명사만, 동의어) 1~2회 재시도한다.
   - 근거 파일이 필요하면 회수된 `파일:줄` 을 직접 열어 문맥을 확인한다.

2. **판단/합성**: 회수된 **발췌만을 근거로** 답한다.
   - canon 에 근거가 있으면: 답변 + 근거(`파일:줄`)를 함께 제시한다.
   - canon 에 근거가 없으면: **지어내지 말고** "canon 에 해당 내용 없음" 이라고 답하고, 필요하면 `lore init`/추가로 정의할 것을 제안한다.

3. **출력 형태**:
   - 사람이 물은 경우: 간결한 자연어 답변 + 근거.
   - 다른 명령의 컨텍스트로 요청된 경우(예: play/art 트랙이 세계관 참조): 관련 발췌를 구조화해 전달하고, 인용한 canon 경로를 명시한다(후속 산출물의 `lore_refs` 기록에 사용).

$ARGUMENTS 가 비어 있으면 무엇을 조회할지 되묻고 멈춘다.
