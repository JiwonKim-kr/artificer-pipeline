# 목적 (goal)

기획서가 이 게임의 **시그니처 메커닉**으로 설계한 "허위 소문은 플레이어가 만들지 않고
대중이 스스로 만든다"(옵션 A)를 구현한다. 지금 엔진은 `수용/역풍/시큰둥` 세 반응만
생성하므로 **`의심` 반응이 영원히 나오지 않고**, 시드에 준비된 찌라시 소재 11종이
죽은 데이터로 남아 있다.

이 메커닉이 채워지면 심사 서사가 완성된다: 플레이어는 진실만 다루는데 **거짓은 여론
스스로 만들어낸다** — "여론은 통제 대상이 아니라 창발한다"는 주제의 가장 선명한 증거.

# 확정 결정 (설계 판단 — 승인 대상)

1. **표현층 한정.** 찌라시는 댓글로만 나타나고 **여론 수치·발각·평판에 영향을 주지 않는다.**
   `opinion_model`(검증된 오라클, 비트-정확 이식)을 **건드리지 않는다** → parity·밸런싱
   재검증 불필요. 창발의 "표현"을 얻되 검증 자산을 지킨다.
2. **자생 조건은 플레이어 행동의 함수.** 무작위가 아니라 기획서 §6 규칙대로 —
   비공개(F11)를 다룰수록, 인격 논쟁(F7/F9)이 뜨거울수록, 무력충돌(F12) 이후, 턴이
   갈수록 확률이 오른다. 즉 **플레이어가 만든 판이 소문을 부른다**(창발의 인과).
3. **소재 게이팅.** 아무 소문이나 뜨지 않는다. `인간재료`=F11(비공개) 계열을 다뤘을 때,
   `일곱이`=F7 보도 후, `소각`=F16 개폐 후. 맥락 없는 소문은 "랜덤"으로 읽히기 때문.
4. **3단계 에스컬레이션.** level 1(의혹 씨앗) → 2(소문 확산) → 3(확신형·명백한 허위).
   단계는 누적 열기(`rumor_heat`)로 오르며 한 번 오르면 내려가지 않는다.
5. **플레이어의 증폭은 이번 범위 밖.** "찌라시를 기사로 단정하면 허위 → 발각축"은
   게임플레이·밸런싱에 영향을 주므로 **별도 spec**으로 분리한다(범위 밖 참조).

# 아키텍처

```
publish(choices)
  └ 기존: 세그먼트별 수용/역풍/시큰둥 댓글 1개씩
  └ 신규: _rumor_step(reported)          # 열기 갱신 + 자생 굴림
        ├ rumor_heat += 기여도(F11/F7·F9/F12/턴)
        ├ level = heat 구간 → 1/2/3 (단조 증가)
        └ p = clamp(base + heat·gain) 로 굴림 → 성공 시
              활성 소재 중 하나의 level 댓글을 1개 추가 (seg=반대층/부동층)
  → comments 배열에 섞여 화면3(댓글 창)에 그대로 표시
```

- 난수는 **댓글 전용 RNG(`_comment_rng`)** 를 쓴다. 발각 굴림용 모델 RNG(비트-정확
  대조 대상)와 절대 공유하지 않는다 — parity 불변 보장.
- 상태는 `TurnManager` 에만 둔다(`rumor_heat`, `rumor_level`, `_rumor_seen`).
  `opinion_model.gd`·`opinion_config.json` **무수정**.

# 대상 파일 (target files)

**코어**
- `src/core/turn_manager.gd` — `_rumor_step()` 신설, `publish()` 반환에 `rumors` 추가.
  상수는 `lever_tuning.json` 으로 뺀다(게임 계층 튜닝 = 데이터, 하드코딩 금지).
- `src/core/lever_tuning.json` — `rumor` 블록 추가:
  `p_base`·`heat_gain`·`level_thresholds`·`contrib`(F11/인격/무력충돌/턴)
- `src/core/data/content_slice.json` — 시드의 찌라시 11종 흡수
  (`rumor`·`level` 필드 포함). 부족한 셀은 `lore export` 로 보강.

**UI**
- `src/ui/main.gd` — 찌라시 댓글을 일반 댓글과 **시각적으로 구분**(색·아이콘 등).
  단정형(level 3)은 더 눈에 띄게. 플레이어가 "이건 사실이 아닌 소문"임을 읽을 수 있어야
  한다(canon 세계 규칙: 정보 전부 진실 ↔ 찌라시는 NPC 발 허위).

**테스트**
- `pipeline/tests/turn_flow_test.gd` — 아래 수용 기준 4·5·6 을 헤드리스로 검증.

# 수용 기준 (acceptance criteria)

1. **자생 발생**: F11(비공개)을 포함해 여러 턴 발행하면 `의심` 반응 댓글이 실제로 등장한다.
2. **무맥락 미발생**: F11·F7·F16 을 한 번도 다루지 않은 진행에서는 해당 소재의 찌라시가
   등장하지 않는다(소재 게이팅).
3. **에스컬레이션**: 열기가 오르면 level 1 → 2 → 3 순으로만 진행하고 역행하지 않는다.
4. **엔진 불변**: `opinion_parity_test` PASS — 골든과 비트-정확 일치(RNG 분리 확인).
5. **밸런싱 불변**: 동일 시드·동일 선택에서 세그먼트 여론값·발각 결과가 이번 변경 전후로
   **동일**하다(찌라시는 표현층이라는 계약의 검증).
6. **결정성**: `turn_flow_test` 가 찌라시 경로를 고정 시드로 재현할 수 있다.
7. 세계관 정합: 찌라시 텍스트가 canon 표기(모르겐社·일곱이 등)를 따른다 — `lore check` 통과.
8. 기존 게이트: 임포트·스모크·매니페스트·네이밍(verify --full) 전부 통과.

# 범위 밖 / 후속

- **플레이어의 찌라시 증폭 → 발각축 편입** (기획서 §6 ⚠️): 게임플레이·밸런싱 영향이
  있어 별도 spec + 몬테카를로 재검증 필요. 이번엔 하지 않는다.
- 찌라시가 여론 수치를 직접 흔드는 것(예: 무관심층 각성) — 같은 이유로 후속.
- 찌라시 대응 액션(해명 기사 등) — 데모 스코프 밖.
