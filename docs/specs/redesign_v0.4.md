## 진단 정정 (2026-08-01, 실코드 확인)
플레이테스트 "정보가 한꺼번에 다 뜨고 재활용" 피드백의 실제 원인:
- `turn_manager.get_blocks()` 는 **이미 턴 게이팅됨**(`t > model.turn+1 → skip`). content_slice `turn` 값도 비트시트대로 정확. → 원고 창은 정상.
- **진범 = `_make_informant`**: 정보원 "입수 정보" 패널이 `content.facts` **전체(16종)를 순회**하고, 씬 빌드 시 **1회만** 그려져 턴마다 갱신 안 됨. → 첫 턴부터 모든 사실 노출.
- **헤드라인 미사용**: 발행 결과가 상태줄 한 줄. 각 fact 의 `headlines`(프레임별) 데이터가 화면에 안 나옴.

## P1 — 정보 시간축 (정보원 패널 게이팅 + 오늘/이월)
- **가용 사실 = `get_blocks()` 에 등장하는 fact 집합**(코어의 단일 게이팅을 UI가 재사용, 로직 중복 0). hidden(F15)·gated(F16)도 자동 반영.
- `_make_informant` 를 위 가용 집합만 순회하도록 변경 + **턴마다 갱신**(`_refresh_informant()`).
- **오늘/이월 구분**: `fact.turn == model.turn+1` → "● 오늘 입수", 그 이전 → "· 이월(T{n})". 색/뱃지. 패널 타이틀에 "오늘 N · 누적 M".
- 원고 창 블록 헤더에도 동일 뱃지(선택 동작 불변).
- 갱신 트리거: 발행로 턴 진행(`_on_publish`) · 책상 발견 F15(`_search_desk`). 기존 `_refresh_blocks()` 옆에 나란히 호출.

## P2 — 기사 렌더 (헤드라인 + 본문)
- 발행 시 상태줄 대신 **조립된 기사 뷰**: `[헤드라인]` + 본문 5~6줄.
- **헤드라인**: 보도된 fact 중 대표 1개의 `headlines[frame_label]`(찬성각/중립/반대각). 없으면 title 폴백.
- **본문**: included 블록들의 `text` 를 순서대로 5~6줄. (P4 재배치 전까지는 등장 순서.)
- 렌더 위치: 기존 `_status_label` 영역을 기사 카드로 승격(창 프레임 재사용) 또는 발행 후 오버레이. 배치 이동 없음.
- 상태 수치(논조·δ·부동층)는 카드 하단에 작게 유지.
