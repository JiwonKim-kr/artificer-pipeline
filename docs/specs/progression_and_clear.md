## 목적 (goal)

데모의 **핵심 루프를 닫는다**: (1) 시스템 **상태창**으로 승탑자 상태를 보여주고, (2) 몬스터 처치로 **경험치·레벨업**(성장), (3) HP 0 시 **게임오버·재시작**(영구사망/서바이벌), (4) 계단으로 **다음 층 돌파**(등반). 이걸 끝내면 이동→전투→성장→돌파→(사망 시 재시작)의 플레이 가능한 로그라이크 한 판이 완성된다.

## 1. 시스템 / 상태창 (UI)

- 시스템이 승탑자에게 보여주는 인터페이스(canon). 화면 고정 HUD(CanvasLayer)로 **HP · 레벨(LV) · 경험치(EXP 현재/다음) · 현재 층수**를 표시한다. (공격력 범위 표시는 선택)
- **텍스트/바 기반 Godot Control** — 아트 에셋 불필요(무료). placeholder_gen 대상 아님.
- 값이 바뀌면(피격·레벨업·돌파) 즉시 갱신된다.
- UI 코드는 `src/ui/`(AI 자유 영역). core 스탯을 읽기만 한다.

## 2. 성장 (경험치·레벨업)

- 몬스터는 `경험치 보상` 값을 갖는다(종류별 노멀 데이터). 처치한 개체의 보상이 **처치자(승탑자)**에게 누적된다.
- EXP가 **다음 레벨 임계치** 이상이면 레벨업: 레벨 +1, 잉여 EXP 이월, `최대 HP`·`공격력(최소/최대)`이 데이터대로 증가. 다중 레벨업 연쇄 처리.
- 레벨업 시 HP 회복 정책은 **데이터로** 명시(권장: 레벨업 시 최대치까지 회복 — 서바이벌에서 성장이 유일한 회복 보상). EXP 곡선·레벨당 증가치는 노멀 데이터(딕셔너리/리소스). 상수 하드코딩 금지.

## 3. 사망 / 게임오버 (서바이벌·영구사망)

- Spec B의 승탑자 `died` 신호를 받아 **게임오버 상태**로 전환: 던전 입력(이동·행동)을 멈추고 게임오버 화면(텍스트 UI)을 표시.
- **재시작**: 입력 시 새 런 시작 — 층수 1, 레벨 1, HP 최대, **새 던전**(영구사망: 진행·성장 초기화). 로그라이크 원칙.

## 4. 돌파 (등반)

- 승탑자가 **올라가는 계단(`<`, STAIRS_UP)** 칸에 도달해 **돌파 입력**(확인 키) 시 다음 층으로 이동.
- 다음 층: 층수 +1, **새 던전 생성**(시드는 기저 시드+층수에서 파생 → 결정적). 승탑자를 새 층 시작 지점에 배치.
- **HP·성장 이월**(층 사이 무상 회복 없음) — 느린 등반·신중한 전진의 서바이벌 압박. 회복은 레벨업으로만.
- 데모 승리 조건: **10층 돌파 = 1층계(지하 미궁) 완주**. 완주 시 "1층계 돌파" 화면 표시(이후는 데모 범위 밖). 그 전까지는 계속 등반.

## 5. 스킬 (기본 1개 — 강타)

canon의 "조건 만족 시 스킬 획득"을 최소 형태로 구현한다. 데모엔 **액티브 스킬 1개(강타/Power Strike)**만.

- **획득**: 특정 레벨 도달(데이터, 예: LV2)에서 시스템이 강타를 부여한다. 획득 전에는 사용 불가.
- **효과**: 활성화(스킬 입력)하면 승탑자가 "강타 준비" 상태가 된다(턴 미소비, 모드 토글). **다음 범프 공격**의 데미지가 강타 배수/보너스(데이터)만큼 강화되고, 사용 후 **쿨다운 N턴**(데이터) 동안 재활성화 불가. 강화 공격이 실제로 성립할 때 쿨다운이 시작된다.
- 쿨다운은 턴마다 1 감소(turn_manager 연동). 데미지 강화도 시드 RNG 롤 위에 적용해 재현성 유지.
- 상태창에 **스킬 보유·쿨다운(또는 준비 상태)**을 표시한다.
- 강타 배수·획득 레벨·쿨다운은 노멀 데이터. 상수 하드코딩 금지.

## 수용 기준 (acceptance criteria)

관찰 가능한 조건만.

1. 몬스터 처치 → 승탑자 EXP가 그 몬스터의 경험치 보상만큼 증가.
2. EXP가 임계치 도달 → 레벨 +1, 잉여 EXP 이월, 최대 HP·공격력이 데이터대로 증가(다중 레벨업 연쇄 정확).
3. 상태창이 현재 HP·LV·EXP·층수를 표시하고, 값 변화(피격·레벨업·돌파) 시 갱신된다.
4. 승탑자 HP 0 → 게임오버 상태 전환, 던전 이동/행동 입력이 더는 승탑자를 움직이지 않는다.
5. 게임오버에서 재시작 → 층수 1·레벨 1·HP 최대·새 던전(진행 초기화).
6. 승탑자가 `<` 계단에서 돌파 입력 → 층수 +1, 새 던전 생성, 시작 지점 배치.
7. 돌파 후에도 HP·레벨·EXP는 이월된다(무상 회복 없음).
8. 같은 기저 시드 → 층별 던전이 결정적으로 동일(층 시퀀스 재현성).
9. 10층 돌파 → "1층계 돌파" 승리 상태 표시.
10. 계단 아닌 곳에서 돌파 입력은 아무 일도 하지 않는다(오작동 없음).
11. 강타 획득 레벨 전에는 스킬 입력이 강화 상태를 만들지 않는다(획득 조건).
12. 획득 후 강타 활성화 → 다음 범프 공격 데미지가 강타 배수/보너스만큼 강화되고, 이후 쿨다운 동안 재활성화되지 않으며, 쿨다운 경과 후 다시 활성화된다.
13. 메인 씬이 렌더되어 던전 + 상태창 HUD가 함께 보인다(스크린샷 스테이지 통과).
