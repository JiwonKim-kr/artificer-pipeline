# 댓글 텍스트 뱅크 설계 v0.1

> 「태엽 인간」 화면3(미시 피드백)의 댓글 시스템. **런타임은 검색·변주만, 생성은 오프라인 LLM 베이킹.**
> 연동: `opinion-model.mjs`의 `step()` → 세그먼트별 반응 → 댓글 선택. 기획서 7.2(프레임×톤×세그먼트 축소) · 9.3(반복 방어) 준수.

## 1. 댓글의 세 역할 (재확인)
1. **미시 여론 확인** — 어느 세그먼트가 물었고 어디서 역풍인지 날것으로.
2. **찌라시 자생** — "인간이 재료" 등 의심이 NPC 댓글에서 스스로 확산(옵션 A 무결성).
3. **방향 힌트** — 무엇을 건드리면 여론이 흐를지 온도로 암시.

---

## 2. 인덱스 키 (무엇이 댓글을 고르나)

한 기사를 발행하면, **채널이 닿는 각 세그먼트마다** 그 세그먼트의 반응에 맞는 댓글을 뽑아 섞어 보여준다.

| 키 | 값 | 출처 |
|---|---|---|
| `seg` | sns_against / old_for / sns_swing / apathetic | config |
| `frame` | 반대각 / 중립 / 찬성각 | 기사 지배 프레임 |
| `tone` | 자극 / 중립 / 차분 | 기사 톤 |
| `reaction` | 수용 / 역풍 / 시큰둥 / 의심 | **엔진 계산값에서 파생**(§3) |
| `topic` | 실업 / 인격 / 무력충돌 / 유착 / 비공개 / 경쟁 … | 기사 지배 사실(F#) 태그 |

- **1차 검색 키 = `seg` + `reaction`** (반드시). **2차 필터 = `frame`/`tone`/`topic`** (있으면 더 정밀, 없으면 무시).
- 기획서 7.2대로 뉘앙스 전부가 아니라 **지배 프레임 1개 + 톤 + 반응**에만 반응 → 셀 수가 관리 가능.

---

## 3. 엔진 반응 → 댓글 카테고리 매핑 (핵심 브릿지)

`step()`의 `micro[seg]` = `{accepted, dir, strength, ...}`를 4개 반응 카테고리로 환원:

```
reaction(seg) =
  strength < ε_low                     → "시큰둥"   (거의 안 움직임 / 무관심층 기본)
  accepted 이고 dir이 미션 방향(+)     → "수용"     (공감·동조)
  accepted 이고 dir이 미션 역방향(−)   → "수용(반대편)" (상대 진영이 좋아함)
  !accepted (역풍)                     → "역풍"     (반발·조롱)
  + 별도 확률 p_rumor 로                → "의심"     (찌라시, §6) 상단에 끼어듦
```

- `ε_low`는 튜닝값(예: 이동폭 0.005). 무관심층은 대부분 여기로 → 짧은 딴소리.
- **역풍**은 SNS 반대층(확증↑)에서 주로 발생 → 자극 톤 기사일수록 역풍 댓글 강도↑.
- 한 기사에 여러 세그먼트가 닿으므로 결과는 **혼합**(예: 부동층 수용 2 + 반대층 역풍 1 + 의심 1).

## 4. 댓글 엔트리 스키마 (JSON)

```json
{
  "id": "cmt_swing_accept_0007",
  "seg": "sns_swing",
  "reaction": "수용",
  "frame": "찬성각",          // null = 프레임 무관(범용)
  "tone": "자극",             // null = 톤 무관
  "topic": "경쟁",            // null = 주제 무관(범용)
  "weight": 1.0,              // 추출 가중치
  "text": "{키워드} 얘기 들으니까 확실히 {대상} 두고 볼 일은 아닌 듯. 나만 그런가?"
}
```

### 슬롯 (동적 삽입 — 반복 방어 + 관련성)
| 슬롯 | 채우는 값 | 예 |
|---|---|---|
| `{키워드}` | 기사 지배 사실 키워드 | "재교육", "일곱이", "42%", "감사 거부" |
| `{대상}` | 언급 대상 | "모르겐", "소여 위원장", "노조", "요나스" |
| `{수치}` | 기사에 쓰인 숫자 | "8,200명", "30%" |
| `{집단}` | 상대 세그먼트 별칭 | "노조 사람들", "산업가들" |

- 슬롯은 **런타임에 기사 태그에서 채운다.** 같은 템플릿도 키워드가 바뀌면 다르게 읽힘.
- 유저네임은 디젤펑크 톤 핸들 풀에서 랜덤 프리픽스(예: `@톱니공12`, `@치차시민`, `@무쇠팔`).

## 5. 세그먼트별 목소리 가이드 (LLM 작성 지침)

| 세그먼트 | 말투·성향 | 수용 예 | 역풍/반발 예 |
|---|---|---|---|
| **SNS 반대층** (감정↑확증↑) | 격앙·냉소·연대. 확증편향("역시 기레기"). 짧고 날 섬 | (거의 없음) | "이딴 선동에 속을 줄 알고? {대상} 돈 받았나" |
| **올드 찬성층** (감정↓확증중) | 점잖음·질서/진보 옹호. 긴 문장. 훈계조 | "혼란기엔 이런 결단이 필요하지" | "요즘 젊은 것들은 대세를 몰라" |
| **SNS 부동층** (감정↑확증↓) | 흔들림·질문형. 밈·이모지. **주 전장** | "음 근데 {키워드} 보면 일리 있네" | "근데 좀 무섭다… {대상} 믿어도 되나?" |
| **무관심층** (둔감) | 짧음·딴소리. 큰 사건에만 반응 | "뭔 소리야 밥이나 먹자" | (큰 사건 시) "이건 좀 선 넘었는데" |

- 채널 영향: **SNS 발행** = 위 댓글 톤. **올드 발행** = 독자 투고·전화 반응(더 정제된 문어체), 올드 찬성층 중심.

## 6. 찌라시 서브뱅크 (자생·에스컬레이션)

옵션 A: 플레이어가 만들지 않는다. **반대층·부동층 댓글에서 확률적으로 자생**.

- 태그: `rumor:인간재료`, `rumor:일곱이`, `rumor:소각` 등.
- **에스컬레이션 규칙**: 자생 확률 `p_rumor`는 아래에서 상승 →
  - F11(비공개)이 보도/회피될수록, 인격 논쟁(F7/F9)이 뜨거울수록, 무력충돌(F12) 이후.
  - 초반 미미 → 6턴 절정 무렵 최고조.
- **강도 3단계** (문구 톤이 세짐):
  1. 의혹 씨앗: "근데 모르겐은 재료를 왜 안 밝혀?"
  2. 소문 확산: "공장에서 사람이 안 나온다던데 진짜임?"
  3. 확신형(위험): "인간을 갈아 넣는 거임. 확실함." ← 명백한 허위(NPC 발화)
- **역할 ③ 힌트 겸용**: 자생한 찌라시가 곧 "이 방향을 건드리면 반대층이 폭발/부동층이 흔들린다"는 신호.
- ⚠️ 플레이어가 이 찌라시를 **기사로 단정·증폭하면** = 허위 → 발각축(스토리 §상단 옵션 A/B). 댓글의 찌라시 자체는 무결성 위반 아님.

## 7. 방향 힌트 처리

별도 콘텐츠가 아니라 **선택·배치로 구현**:
- 반응이 강했던 세그먼트의 댓글을 **상단 고정**(그 프레임이 먹혔다는 신호).
- 특정 `topic` 댓글이 몰리면 = 그 소재가 여론을 흔든다는 암시.
- 편집장/시스템 한 줄 요약(선택): *"부동층이 '{키워드}'에 반응하는 모양이야."* — 힌트를 명시적으로 줄 때만.

---

## 8. 반복 방어 런타임 규칙 (기획서 9.3)

1. 키에 맞는 후보 풀에서 **가중 랜덤 N개** 추출.
2. **최근 M턴에 쓴 id 제외**(쿨다운 큐).
3. 슬롯 채우기(§4) → 같은 템플릿도 표면이 달라짐.
4. 유저네임 랜덤 프리픽스 부착.
5. 풀 고갈 시 `frame/tone/topic=null` 범용 엔트리로 폴백.

---

## 9. 물량 계획 (베이킹 규모)

- 활성 셀 ≈ (세그먼트 3 실질 × 반응 3) = **9 코어 셀** + 프레임/톤/주제 변주.
- 셀당 변주 **4~6개** 목표 → 코어 약 **40~60**개.
- + 찌라시 서브뱅크 **15~20**개(3단계 × 소재별).
- + 무관심층 딴소리 **~10**개.
- **총 ≈ 80~100개** 시드면 데모 한 판(8턴) 반복 티 안 남. 슬롯·랜덤이 체감 다양성을 배가.

## 10. 오프라인 LLM 생성 프롬프트 템플릿

```
너는 가상국가 '아이젠 공화국'의 SNS/신문 댓글 작성기다.
세계관: 디젤펑크, 태엽인(자동인형) 노동 합법화 법안 논쟁.
아래 조건의 댓글을 {N}개, 서로 겹치지 않게 생성하라.

- 세그먼트: {seg 목소리 가이드 §5}
- 반응: {reaction}  (수용=공감 / 역풍=반발·조롱 / 시큰둥=무관심)
- 기사 프레임: {frame} / 톤: {tone} / 주제: {topic}
- 슬롯 사용: 문장에 {키워드}{대상}{수치} 중 자연스러운 것만 남겨라(런타임 치환).
- 길이: 1~2문장. 실제 댓글 말투. 현실 국가·인물·상표 금지.
출력: JSON 배열 [{ "text": "...", "frame":..., "tone":..., "topic":... }]
```

- 찌라시용은 별도 프롬프트: 강도 1/2/3 단계별, 소재(인간재료·소각) 지정.

## 12. 파이프라인 연결
- **오프라인**: §10 프롬프트로 LLM이 대량 생성 → §4 스키마로 태그 인덱싱 → `assets` 또는 `lore/canon` 데이터로 베이킹.
- **런타임**: `step()` 반응 → §3 매핑 → §2 키 검색 → §8 변주 → 화면3 렌더. **LLM 호출 0.**
- 다음 단계: 실제 시드 80~100개 생성(사람 검수 소수 + LLM 대량), config에 `ε_low`·`p_rumor` 상수 추가.
