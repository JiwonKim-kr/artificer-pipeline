# 「태엽 인간」 기사 조각 + 헤드라인 초안 v0.1

> 스토리 v0.3의 F1~F15를 **플레이어 작업 단위**로 분해한 초안.
> **문구는 초안 — 사용자가 다듬는다.** 대량 톤 변주·본문 확장·댓글은 오프라인 LLM 베이킹.
>
> - **조각 태그 기준 = 찬성 미션 관점**: `[유리]`=찬성에 도움 / `[불리]`=반대에 도움 / `[중립]` / `[특수]`=반전·사적.
> - **조각** = 누락·재배치 레버가 작동하는 단위(플레이어가 골라 빼고 순서 바꿈).
> - **헤드라인** = 프레임 선택(찬성각/중립/반대각) 시 표시되는 목소리 앵커.
> - **톤**(자극/중립/차분)은 헤드라인·본문의 리라이팅 → LLM 담당(여기선 미표기).
> - **세계관**: 플레이어국 = **아이젠 공화국**(단일 공화국) ↔ 경쟁국 = **노르덴 연방**(통칭 '연방').

## 찬성 근거

### F1 생산성
**조각**
- `[유리]` 시범공장 분기 산출 42% 증가
- `[유리]` 위험·야간 공정까지 무중단 가동
- `[불리]` 도입 초 3개월 조율로 산출 12% 하락
- `[중립]` 조율 기술자 12명 상주 운영

**헤드라인**
- `[찬성각]` "태엽인 첫 분기, 생산 42% 폭증"
- `[중립]` "태엽인 시범공장, 생산 늘고 조율 진통도"
- `[반대각]` "42%성장의 이면, 석 달의 조업 마비 은폐?"

### F2 안전
**조각**
- `[유리]` 위험 공정 인명 사망 0건
- `[유리]` 고온 주조·갱도에 인간 대신 투입
- `[불리]` 태엽인 오작동 물적 사고 3건 발생
- `[중립]` 오작동 원인 조사 진행 중

**헤드라인**
- `[찬성각]` "죽음의 공정에서 사람이 사라졌다"
- `[중립]` "태엽인 도입 이후 인명사고 0, 기계 오작동 3"
- `[반대각]` "태엽인 통제 못한 오작동 3건 발생, 책임은 누구에게 있나"

### F3 신직종
**조각**
- `[유리]` 정비·조율 기술직 신설, 수료자 임금 인상
- `[유리]` 사양 산업 노동자에 재교육 경로 제공
- `[불리]` 재교육 정원 1,900명뿐
- `[불리]` 미수료 인원 배치 계획 미정

**헤드라인**
- `[찬성각]` "해고 아닌 승진, 태엽인이 연 새 직군"
- `[중립]` "재교육 문 열렸지만 정원은 1,900명"
- `[반대각]` "길거리에 나앉은 6천의 노동자"

### F4 경쟁·국부
**조각**
- `[유리]` 노르덴 연방, 이미 태엽인 양산·시장 선점 중
- `[유리]` 지연 시 수출 계약·국부 유출 우려
- `[불리]` 노르덴 연방은 노동 폭동으로 몸살
- `[중립]` 산업부, 5년 내 격차 경고 보고서

**헤드라인**
- `[찬성각]` "노르덴의 태엽 군단이 국경을 넘본다"
- `[중립]` "태엽인 경쟁, 기회인가 압박인가"

## 사용 메모
- 한 사실의 **사람 작업분 = 조각 4개 안팎 + 헤드라인 3종.** 나머지(톤 변주·본문·댓글)는 LLM 베이킹.
- `[단서]` 조각(F9·F13)은 **지우면 양쪽 프레임이 과격해지는** 창발 지점 → 왜곡 레버의 백미.
- F14는 쓰면 **평판** 하락, F15 공개는 **압박** 상승 — 수치는 안 보이고 암시 문구로만(스토리 §2.4).
- 데모 실사용 사실은 8턴 비트에 맞춰 취사(전 15개를 다 쓰지 않아도 됨).
