# 제출 문서 스켈레톤 (NAN2026 / NHN 게임 AI 해커톤)

> 「태엽 인간」 제출물의 **구조(뼈대)** 모음. 실제 내용이 아니라 **각 섹션에 무엇을·어디서 읽어 채울지**를 정의한다.
> 팀원(또는 에이전트)이 각 파일의 `> [채움]` 지침과 **리포 출처**를 따라 내용을 채운다. 내용이 바뀌어도 이 구조는 유지된다.

## 사용법 (에이전트/사람)
1. 파일의 각 섹션 헤딩 아래 `> [채움]` 지침과 `> [출처]` 경로를 읽는다.
2. `> [출처]`의 리포 파일/데이터를 읽어 사실을 확인하고 섹션을 채운다.
3. `> [팁]`은 프레이밍 가이드. `[대괄호]`는 사람이 확정할 값(실명·URL·플레이시간 등).
4. 채운 뒤 `> [...]` 지침 줄은 삭제한다.

## 기준
- 기준 브랜치 `game/gireki-sim`. 현황은 `docs/build/gireki_dev_guide.md`·`HANDOFF.md`·`/status`.
- 승부처는 **④ AI 활용 기술 문서** — "AI를 많이 썼다"가 아니라 **어디에 안 썼는가(판단력)**가 핵심.
