## 빌드/소스 요건 (#1)
- [ ] 웹 빌드 **GitHub Pages 배포** → 링크 클릭만으로 브라우저 즉시 플레이(유료 라이선스 無, .exe 직접 제출 불가)
- [ ] **게임 전체 소스**를 동일 저장소에 포함 + **커밋 기록 유지**
- [ ] 저장소 **public 권장**. 비공개 시 심사 계정 초대: **dl_gameai_reviewer@nhn.com**

## 유의사항 (위배 시 선발 취소 — 전 문서 공통)
- [ ] **외부 에셋(이미지·사운드 등) 출처 + 라이선스**를 **AI 활용 기술 문서에 반드시 명시**
- [ ] **사용 AI 도구 + 활용 내역**을 반드시 기재
- [ ] 플레이 **동영상에 AI 조작·합성/타인 영상 도용 금지** — 실제 플레이 화면 그대로
- [ ] 타인 저작물·아이디어 무단 도용 금지
- [ ] 제출 링크(GitHub·YouTube)를 **심사 종료까지 접근 가능**하게 유지 (마감 후 변경 불가)
