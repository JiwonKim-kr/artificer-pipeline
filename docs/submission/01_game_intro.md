## 게임 개요 / 세계관

강철과 매연의 제조업 강국 **아이젠 공화국**, 그 수도 '치차'. 의회에 **「노동 근대화법」**(태엽인 — 자동인형 — 의 공장 노동 전면 합법화)이 상정된다. 당신은 석간지 《치차 석간》의 기자. 최대 제조사 **모르겐社**와 산업위원회로부터 **"표결일까지 여론을 찬성으로 돌려달라"**는 의뢰를 받는다. 당신이 쥔 무기는 단 하나 — **정보원이 흘린 진실을, 어떻게 부분·배치·강조하느냐.** 거짓말은 없다. 오직 진실만으로 여론을 빚는다.

## 게임 방법

- **목표**: **8턴 안에 SNS 부동층을 찬성 65% 이상**으로 돌린다.
- **조작**: **마우스 전용.** 모니터 클릭(전원) → 정보원·원고·댓글·여론계 창 → 문장 블록 체크(취사) → 「발행」 → 「받은 자료」·「기사 다시 보기(< >)」 등 버튼.
- **진행(한 턴)**: ① 정보원이 그날의 진실한 문장을 건넴 → ② 실을 문장 취사(불리한 것을 빼면 여론 유리, 발각 리스크↑) → ③ 조합에서 **논조(찬성각/중립/반대각) 창발**, 「헤드라인+본문」 기사 발행 → ④ 여론계·댓글 즉각 반응 → ⑤ 발각·압박·분기.
- **종료 조건**: **부동층 65% 도달 = 성공** / **8턴 초과 = 실패** / **왜곡 발각 누적 = 발각 파탄** / **반대 스탠스 압박 임계 = 배신 파탄**. (성공 시 정직/냉혹 후일담 분기)

## 차별점

**1. 규칙표가 아니라 창발하는 여론.** 결과는 미리 짜인 분기표가 아니라, 검증된 여론 확산 모델(확증편향·역풍·감정 전파·발각/평판)에서 **창발**한다.

**2. "정보가 현실을 만든다"는 주제.** 플레이어의 보도가 회사의 행동을 유발한다 — 일곱이(자아를 가진 듯한 태엽인)를 보도하면 회사가 그 유닛을 조용히 폐기한다.

**3. 디젤펑크 데스크톱 OS 몰입.** 모니터를 켜고 창을 드래그하고 CRT 스캔라인 너머로 취재하는 1인칭 기자 데스크. 아날로그 여론계의 떨리는 바늘이 "여론은 정확히 읽을 수 없다"는 감각을 준다.
