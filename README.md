# 가이드라인 (GUIDELINE)

> 진실만으로도, 여론은 조작된다.

석간지 기자가 정보원에게 받은 **진실한 문장만을 취사·배치**해 8턴 안에 여론을 돌리는 디젤펑크 시뮬레이터. 거짓말은 한 줄도 쓸 수 없다. 쓸 수 있는 건 **무엇을 싣고 무엇을 뺄지**뿐이다.

## 무엇을 하는 게임인가

아이젠 공화국의 수도 치차. 태엽인(자동인형)의 공장 노동을 전면 합법화하는 **「노동 근대화법」** 표결이 여드레 뒤다. 당신은 석간지 《치차 석간》의 기자이고, 산업위원회로부터 의뢰를 받는다 — **표결일까지 SNS 부동층을 찬성 65%로 돌려라. 방법은 묻지 않는다.**

매 턴 정보원이 사실을 물어다 준다. 그 사실들은 **전부 진실**이다. 당신은 문장 블록을 골라 기사를 조립하고 발행한다.

- 유리한 사실을 싣고 **불리한 사실을 빼면** 여론은 찬성으로 기운다
- 대신 **은폐한 만큼 왜곡도(δ)가 올라가고**, 언젠가 들통난다
- 반대로 비판 기사를 계속 실으면 의뢰인이 등을 돌린다

거짓은 게임 안에 존재한다. 다만 **당신이 만들지 않는다** — 대중이 알아서 만든다(→ [찌라시 자생](#찌라시-자생)).

## 규칙

| | |
|---|---|
| 턴 | 8턴 (하루 = 1턴, 표결까지 D-8) |
| 승리 | SNS 부동층(`sns_swing`) 찬성 **65%** 도달 |
| 여론 세그먼트 | 반대층 · 올드미디어 찬성층 · **부동층** · 무관심층 (4종) |
| 패배 | 8턴 소진 → **실패** |
| 파탄 | 왜곡 **3회** 발각 → **발각파탄** / 반대 기사 **4회** 누적 → **배신파탄** |

성공 시 후일담이 갈린다 — 형(테오)의 흔적을 발견하고도 지면에서 뺐다면 **냉혹**, 그 외에는 **정직**.

## 주요 메커니즘

### 문장 취사 = 유일한 레버

기사에 넣은 블록에서 기울기와 왜곡이 도출된다. 태그(유리/불리)는 **내부 계산용이며 화면에 노출되지 않는다** — 무엇이 유리한지는 플레이어가 판단한다.

```
기울기 lean = 유리노출 + 불리은폐 − 불리노출
왜곡    δ   = w_omit × 은폐한 불리 사실 수
```

### 계기에는 눈금이 없다

여론계는 **바늘만 있고 숫자가 없다.** 압박도 수치가 아니라 문구로만 온다("편집국 앞을 '강철 손'이 서성인다"). 정확한 상태를 읽을 수 없다는 게 설계다.

이 원칙은 연출에도 적용된다 — BGM은 위기 곡으로 **한 방향으로만** 바뀐다. 조건에 따라 오갔다 하면 플레이어가 음악을 게이지로 읽어 숨긴 수치가 새기 때문이다. 전환 트리거도 *이미 화면에 드러난 사건*(편집장이 문 앞까지 온 적 있음 / 왜곡이 들통남)으로만 잡았다.

### 찌라시 자생

플레이어가 다루는 정보는 전부 진실이다. **거짓은 대중이 만든다.** 비공개 사실을 감출수록 열기가 쌓이고, 확률 굴림에 걸리면 SNS에 근거 없는 소문이 자란다. 강도는 1(의혹) → 2(확산) → 3(확신형)으로 **단조 증가하며 역행하지 않는다.**

소재는 게이팅된다 — 맥락이 열리지 않은 소문은 나오지 않는다(예: '일곱이' 소문은 F7을 보도해야 열린다). 댓글에 `◆ 확인되지 않은 이야기`로 구분 표시된다.

### 편집장과 분기

비판 기사를 연속으로 실으면 편집장이 경고 창(1) → 노려보는 컷신(2) → 격화(3)로 압박한다. F7을 반대각으로 보도하면 새 취재선(F16)이 열리고, 찬성각으로 덮으면 닫히며 흔적만 남는다.

## 아키텍처 — 2계층 + 비트-정확 대조

여론 모델은 **JS 오라클**(`sim/opinion-model/`)과 **GDScript 런타임**(`src/core/`) 두 벌로 존재하고, `opinion_config.json` 하나를 공유한다. JS 쪽에서 몬테카를로로 밸런싱을 돌리고, GDScript 쪽이 그 결과와 **비트 단위로 일치하는지** 매 검증마다 대조한다.

```
sim/opinion-model/*.mjs  ──┐
                           ├── opinion_config.json (단일 정본)
src/core/opinion_model.gd ─┘
        ↕ opinion_parity_test.gd — RNG·세그먼트·발각 경로 비트-정확 일치
```

`sim/`은 웹 빌드에 포함되지 않는다(개발 도구).

## 로컬에서 돌리기

```bash
godot --path .
```

웹 빌드:

```bash
godot --headless --import && godot --headless --export-release "Web"
```

전체 검증 (게이트 5 + 러너 8):

```bash
python3 pipeline/scripts/verify.py --full
```

게임 전용 테스트 — 파이프라인 러너와 달리 이 게임의 씬·모델에 의존하므로 개별 실행한다:

```bash
godot --headless --path . --script res://pipeline/tests/opinion_parity_test.gd   # 여론 모델 JS↔GDScript 대조
godot --headless --path . --script res://pipeline/tests/turn_flow_test.gd        # 턴 흐름·분기·찌라시
godot --headless --path . --script res://pipeline/tests/bgm_flow_test.gd         # BGM 상태 전환
```
